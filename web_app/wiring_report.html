Diagnostic Fault Trees & Recovery Runbooks

Technician Sync Failure Checklist:

  1. Verify local device Wi-Fi or cellular connectivity.
  2. Check server uptime via GET /api/health.
  3. Confirm session token validity; if expired, prompt user to log in again.
  4. Check SQLite lock state on server (inspect for hanging transactions).
