# Project Rules & Guidelines: Enterprise GPON Network Mapping System

## 1. Strict General Project Rule — No Brand Names
- **Generic Invariant**: This project is a **general enterprise GPON Network Mapping and Field Survey platform**.
- **Zero Brand Name Policy**: **NEVER** include "BSNL", "Kerala Telecom Circle", or any specific telecom operator/carrier brand names anywhere in reports, presentations, code, documentation, database comments, or UI text.
- **Enterprise Terminology**:
  - Refer to the project as **"Enterprise GPON Network Mapping System"**, **"Telecom Optical Distribution Network Management"**, or **"Field Survey & Infrastructure Platform"**.
  - Refer to operational regions as regional telecom operating zones (e.g. "Kochi Region", "Kollam Center", "Zone A / Zone B").
