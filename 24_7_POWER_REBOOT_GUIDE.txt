--------------------------------------------------------------------------------
1. THE 4 LAYERS OF REBOOT SURVIVAL
--------------------------------------------------------------------------------
To ensure your server survives a power outage or unexpected reboot and resumes
without requiring anyone to touch the computer or type passwords:

Layer 1: Hardware / BIOS Level
         When wall electricity returns, the physical PC must turn itself ON
         automatically without pressing the power button.

Layer 2: Operating System (Ubuntu Sleep Prevention)
         Ubuntu Desktop must NEVER enter "Sleep" or "Suspend", which disables
         network cards and disconnects surveyors.

Layer 3: Application & Background Services
         The survey web server (gpon-server), the public tunnel (tailscaled /
         cloudflared), and the Google Drive backup (cron) must start on boot.

Layer 4: Auto-Resume Network Tunnel
         Tailscale Funnel restores its proxy state to port 9001 automatically.

3. MANUAL STEP-BY-STEP CONFIGURATION (FOR REFERENCE)
--------------------------------------------------------------------------------

STEP 3.1: Enable GPON Survey Web Server on Boot
----------------------------------------------
[Where to enter: ANY TERMINAL]

sudo systemctl daemon-reload
sudo systemctl enable gpon-server.service
sudo systemctl restart gpon-server.service

Verify it is enabled:
systemctl is-enabled gpon-server
(Should print: "enabled")


STEP 3.2: Enable Tailscale Daemon on Boot
-----------------------------------------
[Where to enter: ANY TERMINAL]

sudo systemctl enable tailscaled.service
sudo systemctl restart tailscaled.service

Verify it is enabled:
systemctl is-enabled tailscaled
(Should print: "enabled")

Note on Tailscale Funnel:
Tailscale saves your background Funnel configuration in /var/lib/tailscale/.
Whenever tailscaled starts upon boot, it automatically restores the Funnel link
(https://network-mapping.tail1add79.ts.net/) to port 9001!


STEP 3.3: Enable Cron (30-Minute Google Drive Backups) on Boot
--------------------------------------------------------------
[Where to enter: ANY TERMINAL]

sudo systemctl enable cron.service
sudo systemctl restart cron.service

Verify it is enabled:
systemctl is-enabled cron
(Should print: "enabled")


STEP 3.4: Enable Cloudflare Tunnel (If using network-mapping.online)
-------------------------------------------------------------------
[Where to enter: ANY TERMINAL]

If you use Cloudflare Tunnel as a system service:
sudo systemctl enable cloudflared.service
sudo systemctl restart cloudflared.service


STEP 3.5: Disable Ubuntu Desktop Sleep & Suspend (CRITICAL)
----------------------------------------------------------
[Where to enter: ANY TERMINAL]

On Ubuntu Desktop, the system is configured by default to "Suspend" or "Sleep"
after 15 to 20 minutes if no keyboard or mouse is touched. When Ubuntu sleeps:
- The network adapter is powered down.
- All incoming HTTP connections are refused.
- Field surveyors see "Server Disconnected (Offline)".

To permanently block Ubuntu from ever going to sleep:

sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target

This guarantees the desktop remains awake 24 hours a day, 7 days a week.

4. HARDWARE BIOS SETUP: AUTO POWER-ON AFTER ELECTRICITY CUT
--------------------------------------------------------------------------------
When mains power cuts out and comes back, desktop PCs normally stay turned OFF.
To make your PC turn ON automatically when electricity returns:

1. Restart or turn on your Ubuntu desktop computer.
2. Immediately tap the BIOS setup key repeatedly:
   - For Dell:        Tap F2 or F12
   - For HP:          Tap F10 or Esc
   - For Lenovo:      Tap F1 or F2
   - For Asus / MSI:  Tap Del or F2
   - For Gigabyte:    Tap Del

3. In the BIOS setup screen:
   Navigate to the "Power", "Advanced", or "APM Configuration" menu.

4. Look for one of these setting names:
   - "Restore on AC Power Loss"
   - "AC Back"
   - "State After G3"
   - "After Power Failure"

5. Change the value from [Power Off] to:
   --> [Power On]  (or [Always On] / [Last State])

6. Press F10 to Save and Exit.

Result:
Whenever mains power is cut and restored, the physical computer will turn on,
boot into Ubuntu, start gpon-server, launch Tailscale Funnel, and resume your
Google Drive backups automatically without anyone touching the machine!
