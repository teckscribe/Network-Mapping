--------------------------------------------------------------------------------
1. OVERVIEW & SAFETY ARCHITECTURE
--------------------------------------------------------------------------------
This solution automatically backs up your live survey database directly to your
Google Drive at whatever interval you specify (e.g. every 2 hours, every 4
hours, or daily).

Key Safety Features:
1. Zero Data Corruption (Hot SQLite Snapshot):
   The script uses SQLite's official online backup API ("sqlite3 ... .backup")
   to create a 100% clean, uncorrupted database snapshot without stopping the
   gpon-server service or interrupting field surveyors.
2. Complete System Bundle:
   Packages the SQLite database, user accounts (users_config.json), and node
   master hierarchy (custom_hierarchy.json) into a compressed archive:
     gpon_backup_YYYY-MM-DD_HH-MM-SS.tar.gz
3. Automatic Cloud Upload:
   Uploads the archive directly into a dedicated "GPON_Backups" folder in your
   Google Drive.
4. Auto-Pruning & Retention:
   Keeps 7 days of local backups on your Ubuntu desktop and automatically prunes
   Google Drive backups older than 30 days to save cloud storage.

STEP 2.1: Install Required Tools on Ubuntu
------------------------------------------
[Where to enter: ANY TERMINAL]

Open your Ubuntu terminal and run:

sudo apt update
sudo apt install -y rclone sqlite3


STEP 2.2: Connect Rclone to Your Google Drive (One-Time Setup)
--------------------------------------------------------------
[Where to enter: ANY TERMINAL]

Run the interactive configuration wizard:

rclone config

Follow these exact interactive prompts:

1. "No remotes found, make a new one?"
   Type:  n  (and press Enter)

2. "name>"
   Type:  gdrive  (and press Enter)
   (IMPORTANT: Use "gdrive" in lowercase, as the script looks for this exact name).

3. "Storage>"
   Type:  drive  (or enter the number corresponding to "Google Drive")
   Press Enter.

4. "client_id>"
   Leave blank (Press Enter).

5. "client_secret>"
   Leave blank (Press Enter).

6. "scope>"
   Choose full access:
   Type:  1  (Full access all files, except Application Data Folder)
   Press Enter.

7. "service_account_file>"
   Leave blank (Press Enter).

8. "Edit advanced config?"
   Type:  n  (Press Enter).

9. "Use web browser to automatically authenticate rclone with remote?"
   Type:  y  (Press Enter).

   --> A web browser window will automatically pop up on your Ubuntu screen.
   --> Choose your Google Account.
   --> Click "Allow" to grant Rclone permission to access your Google Drive.
   --> The browser will display: "Success! All done. Please go back to rclone."

10. "Configure this as a Shared Drive (Team Drive)?"
    Type:  n  (Press Enter).

11. "Keep this "gdrive" remote?"
    Type:  y  (Press Enter).

12. "q) Quit config"
    Type:  q  (Press Enter).

Setup complete! Rclone is now securely linked to your Google Drive.

3. SCHEDULING AUTOMATIC BACKUPS (CRON)
--------------------------------------------------------------------------------
[Where to enter: ANY TERMINAL (Main terminal or Project terminal - works identically)]

Ubuntu uses "cron" as a system-wide background scheduler for your user account.
It does not matter which directory your terminal is currently in.

To open your schedule table, run:

crontab -e

(If it asks you to choose an editor, select "1" for nano).

Scroll to the bottom of the file and paste YOUR CHOSEN INTERVAL line from below:

OPTION 0: Every 30 Minutes (High Frequency - Real-time Field Protection)
-------------------------------------------------------------------------
*/30 * * * * /home/psms/Network-Mapping/backup_to_gdrive.sh >/dev/null 2>&1

OPTION A: Every 2 Hours (Recommended for standard survey days)
-----------------------------------------------------------------
0 */2 * * * /home/psms/Network-Mapping/backup_to_gdrive.sh >/dev/null 2>&1

OPTION B: Every 4 Hours
-----------------------
0 */4 * * * /home/psms/Network-Mapping/backup_to_gdrive.sh >/dev/null 2>&1

OPTION C: Every 6 Hours (4 times a day: 12 AM, 6 AM, 12 PM, 6 PM)
-------------------------------------------------------------------
0 */6 * * * /home/psms/Network-Mapping/backup_to_gdrive.sh >/dev/null 2>&1

OPTION D: Daily at 8:00 PM (After field survey work ends)
----------------------------------------------------------
0 20 * * * /home/psms/Network-Mapping/backup_to_gdrive.sh >/dev/null 2>&1

OPTION E: Daily at Midnight (12:00 AM)
--------------------------------------
0 0 * * * /home/psms/Network-Mapping/backup_to_gdrive.sh >/dev/null 2>&1

Save and Exit nano:
- Press:  Ctrl + O  then  Enter  (to save)
- Press:  Ctrl + X  (to exit)

Verify that the cron schedule is active [ANY TERMINAL]:
crontab -l

--------------------------------------------------------------------------------
5. DISASTER RECOVERY: HOW TO RESTORE FROM GOOGLE DRIVE
--------------------------------------------------------------------------------
[Where to enter: ANY TERMINAL]

If your Ubuntu desktop is ever formatted, replaced, or damaged:

1. List available cloud backups:
   rclone ls gdrive:GPON_Backups

2. Download your chosen backup archive:
   mkdir -p /home/psms/restore_temp
   rclone copy gdrive:GPON_Backups/gpon_backup_YYYY-MM-DD_HH-MM-SS.tar.gz /home/psms/restore_temp/

3. Extract the archive:
   cd /home/psms/restore_temp
   tar -xzf gpon_backup_YYYY-MM-DD_HH-MM-SS.tar.gz

4. Stop the server service:
   sudo systemctl stop gpon-server

5. Restore the files into your project folder:
   cp snapshot_*.db /home/psms/Network-Mapping/gpon_survey_data.db
   cp users_config.json /home/psms/Network-Mapping/users_config.json
   cp custom_hierarchy.json /home/psms/Network-Mapping/custom_hierarchy.json

6. Restart the server service:
   sudo systemctl start gpon-server

All survey records, user logins, and node hierarchy are 100% restored!
